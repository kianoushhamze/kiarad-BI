# بررسی مستقل از سرور شرکت — ۲۴ آبان ۱۴۰۵

مبنای بررسی `cf9bfccf1bfed3c2e78369f3826385b9a5bccc34` است. کاربر خواست کارهای قابل انجام در غیاب سرور شرکت انجام شوند. آزمون‌ها در محیط Linux، PostgreSQL16 جداگانه و با دادهٔ ساختگی انجام شدند؛ هیچ اتصال هلو، سفارش، پیام یا دادهٔ واقعی شرکت استفاده نشد.

## یافته‌های اصلاح‌شده

۱. ابزار بسته‌سازی، SHA را از HEAD ولی فهرست blobها را از index می‌گرفت؛ فایل staged می‌توانست با نام نسخهٔ قبلی منتشر شود. ابزارهای کنار ZIP و گزارش‌ها نیز از worktree کپی می‌شدند و حتی ابزار untracked امکان ورود به بسته داشت. سه آزمون مستقل این ناهماهنگی‌ها را پیش از اصلاح بازتولید کردند و شکست خوردند. اکنون inventory از tree همان commit خوانده و با SHA اعلام‌شده تطبیق داده می‌شود؛ ابزارها و هنداف‌ها نیز از بایت‌های تأییدشدهٔ source.zip استخراج می‌شوند.

۲. گزارش تاریخی transfer/validation به‌طور پیش‌فرض در جایگاه شواهد نسخهٔ تازه کپی می‌شد. اکنون فقط --evidence صریح، شواهد بیرونی اضافه می‌کند؛ پوشهٔ validation و kit-scope.json بدون ادعای پذیرش شرکت تولید می‌شوند. گزارش تاریخی همچنان در سورس تاریخچه است. آزمون جدا این تفکیک را بررسی می‌کند.

۳. npm run typecheck در checkout تازه، LayoutProps تولیدنشده را پیدا نمی‌کرد. مطابق راهنمای همراه Next.js16.3.1، typegen پیش از tsc اجرا می‌شود. فرمان اصلاح‌شده موفق شد. CI قبلی این پیش‌نیاز را جدا اجرا می‌کرد و به همین دلیل نقص فرمان محلی را نشان نمی‌داد.

## شواهد محلی

- آزمون آفلاین پس از اصلاح بسته‌سازی و تحویل: ۹۱۳ کشف‌شده، ۶۳۰ موفق، ۲۸۳ skip، صفر شکست/خطا؛ شامل چهار آزمون یکپارچگی سورس و نه آزمون محافظت آرشیو تحویل. skip معادل pass نیست.
- PostgreSQL16 ایزوله: هر۳۰گروه، مجموع۳۵۷آزمون موفق.
- تمام tests/node/*.mjs و kiarad-dashboard/scripts/test-*.cjs موفق؛ درخواست‌ها mock هستند.
- lint: صفر خطا و دو هشدار قدیمی img در CMS؛ بررسی نوع اصلاح‌شده موفق؛ build تولیدی۵۴مسیر موفق.
- Chromium واقعی فروشگاه: ثبت‌نام، سبد و رسید سفارش ساختگی در عرض‌های۳۶۰،۳۹۰،۶۴۰و۱۲۸۰ موفق، بدون خطای runtime.
- جزوهٔ فارسی PDF و HTML با فونت محلی تولید شد.
- API واقعی روی دیتابیس ساختگی: ۱۳ آزمون نقش‌ها، منابع داشبورد، گردش‌های خواندنی و پاسخ‌های مستند دستیار موفق؛ مدل خارجی فراخوانی نشد.
- واسط کانتینری واقعی Traccar: دریافت image موفق ولی docker run با کمبود فضای دیسک متوقف شد؛ نتیجه blocked است. تصویر دریافت‌شده و کش ساخته‌شدهٔ همین کار پاک شدند؛ دیتابیس آزمایشی و شواهد آزمون‌ها حفظ شدند. آزمون‌های SQL مربوط به GPS در۳۰گروه موفق بالا هستند، اما اجرای پروتکل واقعی این نوبت موفق اعلام نمی‌شود.

این مرور، ممیزی کامل امنیت یا آزمون همهٔ فرم‌های محصول نیست. آزمون مدل خارجی دستیار، PowerShell5.1 روی Windows، پنج تصویر نهایی Docker و پذیرش گوشی/شرکت از نتایج بالا استنتاج نمی‌شوند. بستهٔ محلی سبک است و تصاویر آماده ندارد؛ workflow موجود امکان تولید بستهٔ پنج‌تصویری را پس از بررسی همان SHA دارد.
