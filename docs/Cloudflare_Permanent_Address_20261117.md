# آدرس دائمی Cloudflare — kiaradhealer.ir

> **وضعیت: آماده برای اجرا، هنوز اجرا نشده.** این سند و اسکریپت فقط آماده‌سازی نرم‌افزاری‌اند. ساخت تونل نیاز به ورود به حساب Cloudflare مالک دامنه و اجرا روی سرور شرکت (`DESKTOP-TGAKM7L`) دارد. تا خروجی واقعی اجرا ثبت نشود، آدرس‌ها «ساخته‌شده» اعلام نمی‌شوند.

## پیش‌نیاز (مالک دامنه)

1. در dash.cloudflare.com دامنهٔ `kiaradhealer.ir` را با پلن Free اضافه کنید.
2. دو Nameserver دادهشده را در پنل رجیسترار جایگزین کنید.
3. صبر کنید وضعیت دامنه **Active** شود (برای `.ir` ممکن است از دقایق تا ساعت‌ها طول بکشد).

## اجرا روی سرور

```powershell
cd D:\Kiarad-Stage-20261114
git pull   # فقط اگر سورس سرور git است؛ وگرنه فایل را دستی کپی کنید
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\cloudflare\kiarad_cloudflare_named_tunnel_v2.ps1
```

- دامنه: Enter برای پیش‌فرض `kiaradhealer.ir`.
- GPS: فعلاً `N`.
- مرورگر باز می‌شود؛ دامنه را انتخاب و تأیید کنید.

اسکریپت: cloudflared را آماده می‌کند، تونل `kiarad-stage` را می‌سازد، `config.yml` را اعتبارسنجی می‌کند، رکوردهای DNS را می‌سازد، سرویس خودکار `KiaradCloudflared` (با restart بعد از خطا) نصب می‌کند و دو آدرس را از خود سرور آزمایش می‌کند. Quick Tunnel فعلی را تغییر نمی‌دهد. `.env`، compose و داده‌ها دست‌نخورده می‌مانند.
