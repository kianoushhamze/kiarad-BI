# کیاراد همراه — اندروید و آیفون

اپ بومی مشترک React Native / Expo 58 برای شیفت رضایت‌محور، مکان‌یابی پس‌زمینه، صف آفلاین و دریافت/گزارش وظایف. نسخهٔ۱٫۱ ترکیبی است: پنل کامل مجاز کاربر در WebView امن داخل اپ و فقط همان دامنهٔ HTTPS باز می‌شود. GPS و صف محلی بومی و مستقل از صفحهٔ پنل‌اند. پنل کامل آنلاین است؛ همهٔ فرم‌ها دوباره با رابط بومی بازنویسی نشده‌اند. نشست در URL قرار نمی‌گیرد. خروجی مجاز تا۱۰مگابایت با تأیید کاربر به برگهٔ اشتراک‌گذاری منتقل و فایل موقت پاک می‌شود.

## اتصال

در اپ فقط **مبدأ HTTPS پنل** مثل `https://panel.company.ir` وارد شود، بدون `/api` یا مسیر دیگر. اپ درخواست‌ها را به `/api/auth/login` و `/api/tracking/...` می‌فرستد. پراکسی هم‌مبدأ Next باید به بک‌اند متصل باشد. حساب، حساب پرسنلی پنل است؛ برای شیفت به `salesperson_id` معتبر نیاز دارد. حساب مشتری فروشگاه مناسب نیست.

توکن و مشخصات نشست در SecureStore، نقاط در SQLite خصوصی اپ ذخیره می‌شوند. هر نقطه UUID دارد و فقط پس از تأیید سرور از صف حذف می‌شود. خروج و تعویض حساب تا پایان شیفت و تخلیهٔ صف محدود است. حذف برنامه، پشتیبان صف نیست.

## توسعه و بررسی

```sh
npm ci
npm run typecheck
npm test
npx expo export --platform all
npx expo prebuild --platform android
npx expo prebuild --platform ios
```

Expo Go برای تأیید مکان‌یابی پس‌زمینه کافی نیست. پروژه‌های `android/` و `ios/` خروجی تولیدی‌اند و version نمی‌شوند. `package-lock.json` نسخه‌های وابستگی را تثبیت می‌کند.

## اندروید

CI پروژهٔ بومی را تولید و `assembleRelease` اجرا می‌کند. خروجی **APK پایلوتِ مستقل از Metro، با کلید آزمایشی** است؛ امضای تولید و انتشار فروشگاهی جداست. برای انتشار پایدار، keystore سازمان در مخزن اسرار نگهداری و فایل با امضای پایدار تولید شود. امضای debug هر runner می‌تواند متفاوت باشد؛ به‌روزرسانی روی نصب قبلی باید پیش از توزیع کنترل شود. هیچ‌گاه برای رفع ناسازگاری امضا، اپ دارای صف ارسال‌نشده را حذف نکنید.

دسترسی مکان دقیق، مکان در پس‌زمینه، سرویس foreground و وضعیت باتری در مدل‌های واقعی شرکت آزمون شوند. اعلان ثبت مسیر و نشانگر سیستم برای آگاهی فرد حفظ می‌شوند.

## آیفون

CI روی macOS، Pods و پروژهٔ `KiaradField.xcworkspace` را ساخته و برای iOS Simulator با `CODE_SIGNING_ALLOWED=NO` کامپایل می‌کند. این خروجی **IPA قابل نصب روی آیفون نیست**. نصب واقعی به Apple Developer تیم شرکت و امضای مجاز نیاز دارد. شناسهٔ بسته `ir.kiarad.field` است؛ مالکیت آن و روش TestFlight/توزیع باید با حساب شرکت تطبیق یابد. گواهی، پروفایل و رمز در repo یا چت قرار نگیرد.

برای دستگاه، پروژهٔ تولیدشده در Xcode باز، Team و Signing انتخاب، سپس Archive و توزیع مجاز انجام شود. Always و Precise Location و UIBackgroundModes/location فعال است؛ پذیرش نهایی حتماً روی آیفون واقعی انجام شود.

## رفتار و محدودیت

- شروع شیفت با رضایت صریح کاربر؛ پیش‌فرض ۸ ساعت، فقط همان نشست دستگاه/حساب.
- درخواست نمونه‌برداری حدود ۳۰ ثانیه/۱۵ متر است؛ سیستم‌عامل ممکن است زمان‌بندی را تغییر دهد.
- نقاط قدیمی با زمان اصلی ارسال می‌شوند و زنده نامیده نمی‌شوند.
- force-stop، خاموشی، لغو مجوز یا محدودیت OS می‌تواند ثبت را قطع کند؛ تداوم مطلق تضمین نمی‌شود.
- خارج از بازهٔ نشست، نمونه وارد صف نمی‌شود. سرور نیز بازه را کنترل می‌کند.
- صف تا ۵۰هزار نقطه محدود است؛ سرور برای ارسال آفلاین مهلت هفت‌روزه دارد. اتصال و تخلیهٔ روزانه لازم است.
- قطعی GPS حکم کم‌کاری، کارکرد حقوق یا ویزیت معتبر ایجاد نمی‌کند.
- نقطهٔ خام و توکن در گزارش عمومی یا نشانی URL قرار نمی‌گیرند.

چک‌لیست قفل صفحه، آفلاین، ارسال مجدد، پایان شیفت و نقش‌ها در جزوهٔ PDF و هنداف آمده است.
